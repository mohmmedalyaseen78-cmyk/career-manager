# Career Manager — نسخة المصدر (مرحلة: المحرك + نموذج الواجهة)

لعبة مسيرة تدريبية كروية شخصية غير تجارية، عربية RTL، خفيفة على الأجهزة الضعيفة (الهدف: ASUS K42F / i3 M350 / 6GB / 1366×768).
**الحالة الصريحة: هذه ليست لعبة جاهزة للّعب بعد.** المحرك مكتمل ومختبر، والواجهة نموذج تصميم يعمل على بيانات تجريبية، ولم يُبنَ بعد غلاف ويندوز ولا ربط الواجهة بالمحرك.

## التشغيل
- **اختبارات المحرك:** `python -W ignore -m unittest discover -s tests -t .` (بايثون 3.13، بلا مكتبات خارجية؛ اختبار `test_data_import` يحتاج `pandas`).
- **معاينة الواجهة:** شغّل `tools\run_ui_preview.bat` (أو `cd ui && python -m http.server 8765` ثم افتح `http://127.0.0.1:8765`). لا تفتح `index.html` مباشرة بنقر مزدوج: أيقونات الأقنعة تحتاج HTTP.
- **توليد بيانات المعاينة من المحرك:** `python tools/export_demo.py` (يكتب `ui/data/demo.js`).
- **قياس الأداء:** `python bench.py`.
- **لقطات الشاشة:** `node tools/shots.js` (يتطلب Playwright).
- **توليد الأصول:** `node tools/gen_assets.js`.
- صفحة «حالات العناصر» مرجع تصميم داخلي فقط: لا تظهر في اللعبة، تُفتح بـ `index.html?dev=1#states`.

## المكتمل والمختبر (91 اختباراً ناجحاً)
قاعدة بيانات عالم مشتركة للقراءة فقط + ملف صغير لكل مسيرة · مسيرات متعددة (إنشاء/فتح/حفظ تلقائي/نسخ احتياطي/حذف بتأكيد) · 35 سمة لاعب وOVR موزون بالمركز مع وسم مصدر كل رقم · مواهب عربية عشوائية فريدة ونمو وندرة النخبة · جدول مباريات 10 دوريات (5 دول × درجتان) · محاكاة المباراة التفاعلية (تبديلات/خطة/إيقاف) ومحاكاة سريعة · ترتيب تراكمي، صعود/هبوط، نهاية الموسم · **أرشيف الأندية** (بلا سجل لاعبين/مدربين) · هوية المدرب (اسم + صورة محلية) · **المفاوضات الواقعية** (استفسار ← النادي ← العقد، سعر خفي، 4 مستويات صعوبة) · **عروض التدريب** والانتقال بين الأندية بنفس المسيرة وتعيين مدرب بديل (بلا إقالة؛ مؤشر ثقة فقط) · مستورد البيانات (CSV ← world.db) · مولّد بيانات 2026/27 (لم يُشغَّل فعلياً، انظر أدناه) · حاكم الموارد.

## نموذج الواجهة (4 شاشات)
البداية، الرئيسية، الفريق (مركز الفريق)، الانتقالات (بحث/مفاوضة جارية) + الشريط العلوي والتبويبات الستة. **كل ما فيها يقرأ من المحرك لكن الأزرار الفاعلة حالياً هي التنقل والتصفية والبحث والفرز واختيار اللاعب؛ باقي الأزرار تعرض رسالة «تُبنى لاحقاً».**

## الناقص (لم يُنجز — لا يوجد ادعاء بغير ذلك)
- غلاف ويندوز (WebView2 أو WinForms) وربط الواجهة بالمحرك عبر جسر، والمثبّت. **لم يُقَس الأداء على الجهاز المستهدف بعد.**
- البيانات الحقيقية: المولّد جاهز لكن لم يُشغَّل (يحتاج GitHub Actions). العالم الحالي **اختباري وهمي** (أندية «نادي تجريبي N») وقيمه مبالغ فيها؛ لا يُعتمد كبيانات اللعبة.
- شاشات: مكتب النادي، البطولات، التقويم ومركز المهام، الأخبار، التكتيك والتدريب والتطوير، واجهات المباراة التفاعلية، شاشة إنجازات الموسم، المفاوضة (واجهة)، عروض التدريب (واجهة)، الإعدادات، الاعتمادات (CC BY-SA)، مسيرة جديدة/تحميل.
- الكؤوس المحلية والمسابقات الأوروبية، المالية والأهداف الكاملة، الحالة (Low Resource Mode) في الواجهة.
- ملاحظات الأصول: رسومات متجهة أصلية (ليست صوراً فوتوغرافية)؛ صور اللاعبين رمادية موحدة بلا وجوه.
