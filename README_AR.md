# Career Manager — نسخة قابلة للّعب (مرحلة أولى)

لعبة مسيرة تدريبية كروية شخصية غير تجارية، عربية RTL، خفيفة على الأجهزة الضعيفة.
**الحالة الصريحة:** اللعبة تعمل كاملة من الواجهة إلى المحرك (اختبرتها عبر 4 مسيرات في المتصفح وعبر موسم كامل بالخادم)، لكن **ملف ويندوز التنفيذي لم يُبنَ بعد** — يُبنى على GitHub Actions بالخطوات في `docs/RUN_AND_DATA_AR.txt` وأسفل هذا الملف. لم يُجرَّب البناء على ويندوز ولا الأداء على جهازك بعد.

## بناء نسخة ويندوز (على GitHub)
1. ارفع المشروع إلى مستودعك (git add . / commit / push).
2. Actions ← **Build Career Manager (Windows)** ← Run workflow.
3. ينفّذ: الاختبارات ← PyInstaller ← **اختبار ذاتي على الـexe المبني نفسه** ← zip محمول + مثبّت Inno Setup (إن نجح).
4. حمّل Artifact `CareerManager-windows`، فك الضغط، شغّل `CareerManager.exe`.
5. للبيانات الحقيقية: ضع `players_2026-27_BASE.csv` (من مخرجات مولّد البيانات) داخل مجلد `data` بجانب الـexe.

## ما يعمل في اللعبة
مسيرات متعددة (جديدة/متابعة/تحميل/حذف بتأكيد) · اختيار أي نادٍ من 10 دوريات · المباراة المباشرة (إيقاف/تشغيل/سرعة/تبديلات/خطة/تشكيل) + محاكاة سريعة + إنهاء فوري · تشكيلة وعقلية وضغط وإيقاع · إصابات وإيقافات وإرهاق ومعنويات وفورمة لفريقك · سوق انتقالات: بحث، لاعبون أحرار، **مفاوضات واقعية بمراحلها (النادي ← اللاعب ← التأكيد)** وتجديد العقود · عروض تدريب والانتقال بين الأندية بنفس المسيرة · ثقة الإدارة (بلا إقالة) · ترتيب الدوريات والنتائج والهدّافون · التقويم · نهاية الموسم: صعود/هبوط، تطوير اللاعبين، عقود، مواهب جديدة بأسماء عربية فريدة · **أرشيف مواسم النادي وشاشة الإنجازات** · حفظ تلقائي ونسخ احتياطي.

## الناقص (لم يُنجز)
- الكؤوس المحلية والمسابقات الأوروبية، والإعارات، وبيع لاعبينك لأندية أخرى (عروض واردة)، والكشّافون، وشاشة التدريب، وصورة المدرب (المحرك يدعمها والواجهة لا).
- أحداث المباراة المباشرة نصية (بلا رسم ملعب).
- الأداء على جهازك غير مقاس. تسريع الرسوم مُعطّل افتراضياً (Edge بالرسم البرمجي) لقِدم كرت الشاشة.
- بدون ملف البيانات تعمل اللعبة بعالم اختباري وهمي (قيمه المالية مبالغ فيها).

## التشغيل
- **اختبارات المحرك:** `python -W ignore -m unittest discover -s tests -t .` (بايثون 3.13، بلا مكتبات خارجية؛ اختبار `test_data_import` يحتاج `pandas`).
- **معاينة/لعب من المصدر:** `python app/dev_server.py 8766` ثم افتح `http://127.0.0.1:8766` (أو `python app/launcher.py` على ويندوز) (أو `cd ui && python -m http.server 8765` ثم افتح `http://127.0.0.1:8765`). لا تفتح `index.html` مباشرة بنقر مزدوج: أيقونات الأقنعة تحتاج HTTP.
- **قياس الأداء:** `python bench.py`.
- **لقطات الشاشة:** `node tools/shots.js` (يتطلب Playwright).
- **توليد الأصول:** `node tools/gen_assets.js`.

## المكتمل والمختبر (91 اختباراً ناجحاً)
قاعدة بيانات عالم مشتركة للقراءة فقط + ملف صغير لكل مسيرة · مسيرات متعددة (إنشاء/فتح/حفظ تلقائي/نسخ احتياطي/حذف بتأكيد) · 35 سمة لاعب وOVR موزون بالمركز مع وسم مصدر كل رقم · مواهب عربية عشوائية فريدة ونمو وندرة النخبة · جدول مباريات 10 دوريات (5 دول × درجتان) · محاكاة المباراة التفاعلية (تبديلات/خطة/إيقاف) ومحاكاة سريعة · ترتيب تراكمي، صعود/هبوط، نهاية الموسم · **أرشيف الأندية** (بلا سجل لاعبين/مدربين) · هوية المدرب (اسم + صورة محلية) · **المفاوضات الواقعية** (استفسار ← النادي ← العقد، سعر خفي، 4 مستويات صعوبة) · **عروض التدريب** والانتقال بين الأندية بنفس المسيرة وتعيين مدرب بديل (بلا إقالة؛ مؤشر ثقة فقط) · مستورد البيانات (CSV ← world.db) · مولّد بيانات 2026/27 (لم يُشغَّل فعلياً، انظر أدناه) · حاكم الموارد.

## نموذج الواجهة (4 شاشات)
البداية، الرئيسية، الفريق (مركز الفريق)، الانتقالات (بحث/مفاوضة جارية) + الشريط العلوي والتبويبات الستة. **كل ما فيها يقرأ من المحرك لكن الأزرار الفاعلة حالياً هي التنقل والتصفية والبحث والفرز واختيار اللاعب؛ باقي الأزرار تعرض رسالة «تُبنى لاحقاً».**

## الناقص (لم يُنجز — لا يوجد ادعاء بغير ذلك)
- غلاف ويندوز (WebView2 أو WinForms) وربط الواجهة بالمحرك عبر جسر، والمثبّت. **لم يُقَس الأداء على الجهاز المستهدف بعد.**
- البيانات الحقيقية: المولّد جاهز لكن لم يُشغَّل (يحتاج GitHub Actions). العالم الحالي **اختباري وهمي** (أندية «نادي تجريبي N») وقيمه مبالغ فيها؛ لا يُعتمد كبيانات اللعبة.
- شاشات: مكتب النادي، البطولات، التقويم ومركز المهام، الأخبار، التكتيك والتدريب والتطوير، واجهات المباراة التفاعلية، شاشة إنجازات الموسم، المفاوضة (واجهة)، عروض التدريب (واجهة)، الإعدادات، الاعتمادات (CC BY-SA)، مسيرة جديدة/تحميل.
- الكؤوس المحلية والمسابقات الأوروبية، المالية والأهداف الكاملة، الحالة (Low Resource Mode) في الواجهة.
- ملاحظات الأصول: رسومات متجهة أصلية (ليست صوراً فوتوغرافية)؛ صور اللاعبين رمادية موحدة بلا وجوه.
