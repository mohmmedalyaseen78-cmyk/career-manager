Career Manager — مولّد بيانات الأندية واللاعبين وOVR لموسم 2026/27
=====================================================================

ماذا تفعل الحزمة؟
-----------------
هذه الحزمة ليست قاعدة بيانات مكتملة مخزنة داخل ZIP. إنها أداة توليد تلقائي تنزّل المصادر العامة وتنتج CSV فعلياً عبر GitHub Actions، حتى لا يحتاج Claude إلى قراءة أو كتابة آلاف الأسماء يدوياً.

عند تشغيل Workflow تنتج الملفات التالية:
1) players_2026-27_OVR.csv
   الملف الأساسي للعبة: الدولة، الدوري، الدرجة، النادي، اسم اللاعب، المركز، OVR فقط.
   لا يتضمن PAC أو SHO أو PAS أو DRI أو DEF أو PHY.
2) players_2026-27_OVR_AUDIT.csv
   نسخة تدقيق داخلية توضّح مصدر OVR وهل هو من قاعدة EA الرسمية أو تقدير داخلي، مع روابط المصدر وسجل القائمة.
3) clubs_2026-27.csv
   قائمة الأندية المستخرجة من مصدر الموسم الحالي، حتى الأندية التي قد لا تكون قائمة لاعبيها مكتملة.
4) coverage_2026-27.csv
   مقارنة عدد الأندية المتوقع، وعدد الأندية في المصدر، وعدد الأندية التي ظهرت لها قائمة لاعبين. لا تستورد قاعدة البيانات قبل مراجعة هذا الملف.
5) DATA_METADATA.json
   تاريخ الجلب، الإصدارات والمصادر، عدد المطابقات الرسمية والتقديرات، والتنبيهات المتعلقة بالترخيص.

نطاق اللعبة: 10 دوريات / 198 نادياً متوقعاً
------------------------------------------
England: Premier League (20) + Championship (24)
Spain: LaLiga (20) + Segunda División (22)
Germany: Bundesliga (18) + 2. Bundesliga (18)
Italy: Serie A (20) + Serie B (20)
France: Ligue 1 (18) + Ligue 2 (18)

مصدر قوائم الأندية واللاعبين
----------------------------
OpenFootballBase-Data — الإصدار المثبّت data-1.24.0، المنشور 21 نوفمبر 2026:
https://github.com/florentfougeres/OpenFootballBase-Data/releases/tag/data-1.24.0

المصدر يجمع قوائم الموسم من صفحات Wikipedia وبيانات Wikidata، ويحتفظ بمرجع الصفحة ورقم المراجعة. تغطية 2026/27 للدوريات العشرة المحددة أظهرت 198/198 نادياً بقوائم في لقطة PROGRESS المنشورة بتاريخ 16 نوفمبر 2026، لكن يجب مراجعة تقرير التغطية الناتج من الإصدار الذي تم تنزيله نفسه؛ لا نفترض أن كل اسم أو انتقال تم تحديثه لحظياً.
تقرير المصدر:
https://raw.githubusercontent.com/florentfougeres/OpenFootballBase-Data/main/PROGRESS.md

مصدر OVR الرسمي
----------------
السكربت يحاول جلب OVR الأساسي للاعب من صفحة EA الرسمية:
https://www.ea.com/games/ea-sports-fc/ratings

تستخدم EA قاعدة Ratings الرسمية التي تعرض قيم OVR لبطاقات Gold/Silver/Bronze الأساسية في Ultimate Team 27 عند الإطلاق. هذا تقييم EA منشور رسمياً، لكنه ليس بالضرورة Dynamic OVR المستخدم في Career Mode ولا يتضمن تحديثات الفورمة الحية في الأنماط الأخرى. لذلك يسميه الملف EA_OFFICIAL_BASE_ITEM ولا يدّعي أنه تقييم Career Mode مباشر.

يستخدم السكربت واجهة البيانات العامة التي تغذي صفحة EA. هذه الواجهة غير موثقة كواجهة مطور مستقرة وقد تتغير؛ إذا توقفت أو رفضت الطلبات، لا يتوقف التوليد: يستخدم التقدير الداخلي ويكتب حالة الفشل في DATA_METADATA.json. لا يتم نسخ أي قدرة فرعية من EA إلى ملف اللعبة.

سياسة المطابقة:
- تتم المطابقة بالاسم المعياري.
- إذا تكرر الاسم، يجب أن تطابق هوية النادي بشكل فريد.
- إذا بقيت المطابقة ملتبسة، لا نخمن؛ نستخدم OVR التقديري.
- التقييم الرسمي المستخدم هو OVR فقط.

التقدير الداخلي عند غياب رقم رسمي
---------------------------------
التقدير موسوم ESTIMATED ولا يجوز عرضه على أنه رسمي. يعتمد بصورة محافظة على:
- مستوى الدرجة كخط أساس.
- العمر.
- إحصائيات عامة حديثة متاحة في مصدر البيانات (المشاركات والأهداف والتمريرات الحاسمة عند وجودها).
- مشاركات المنتخب الأول.
- إشارات الجوائز المتاحة.
- مقارنة داخلية مع لاعبي المركز نفسه في الدوري نفسه.

إذا لم تتوفر إحصائيات للاعب، لا يحصل على مكافأة أداء مفترضة. ولا ينتج السكربت أي PAC/SHO/PAS/DRI/DEF/PHY.

ملاحظة الترخيص
--------------
المصدر يذكر أن البيانات المستمدة من Wikipedia تخضع لـ CC BY-SA 4.0 مع الإسناد، وأن Wikidata تحت CC0، وأن كود المستودع مرخّص MIT. إذا قررت نشر قاعدة البيانات أو توزيعها مع اللعبة، راجع شروط المصدر والإسناد والمشاركة بالمثل قبل التوزيع التجاري أو العام. لا يعني كون المصدر قابلاً للتنزيل أن كل استخدام أو إعادة توزيع بلا قيود.

طريقة التشغيل عبر GitHub Actions
--------------------------------
1) ضع ملفات هذه الحزمة في مستودع Career Manager الخاص. انسخ مجلد data_import إلى جذر المستودع أو حافظ على مساراته وعدّل workflow وفق ذلك.
2) يجب أن يكون:
   - build_squads.py في نفس مستوى requirements.txt.
   - مجلد .github/workflows/ يحتوي build_squads.yml.
   - ملف official_ovr_overrides_template.csv متاحاً كقالب اختياري.
3) افتح تبويب Actions في GitHub.
4) اختر Build Career Manager 2026-27 squads and OVR.
5) اضغط Run workflow.
6) بعد اكتمال التشغيل، افتح Summary ثم Artifacts ونزّل career-manager-2026-27-rosters-and-ovr.
7) افتح coverage_2026-27.csv أولاً.
8) استخدم players_2026-27_OVR.csv للاستيراد إلى اللعبة، واحتفظ بملف AUDIT لأغراض التوثيق فقط.

كل التنزيلات والمعالجة تتم على GitHub-hosted runner، وليس على لابتوب المستخدم. لا يحتاج Claude إلى كتابة أسماء اللاعبين يدوياً.

اختبار الحزمة
-------------
تم فحص سلامة صياغة Python (compile check) للحزمة عند إعدادها. لم يتم تشغيل تنزيل الأرشيف أو EA API داخل هذه البيئة؛ لذلك لم يتم إنشاء CSV اللاعبين الفعلي هنا ولم يتم تأكيد عدد صفوفه النهائي. يتولد ذلك عند تشغيل Workflow.

تحديث المصدر مستقبلاً
---------------------
الإصدار مثبت data-1.24.0 لضمان إعادة إنتاج نفس لقطة البيانات. قبل تحديث الموسم أو البيانات، افحص أحدث Release في مستودع OpenFootballBase-Data، ثم غيّر RELEASE_TAG بعد مراجعة سجل التغييرات وتوافق المخطط.
